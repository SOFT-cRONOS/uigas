── ESPACIADO Y GRID ─────────────────────────────

- Contenedor: max-width 1360px, gutter 24px (px-6).
- Grid: los breakpoints son los de Bootstrap (sm 576 / md 768 / lg 992 /
  xl 1200 / xxl 1400).
- Escala de radios (sin chaflán):
  --bs-border-radius-sm 2px  ·  -base/-lg 4px  ·  -xl 6px  ·  -xxl 8px
  -pill 50rem (round completo)


── COMPONENTES DE UI ────────────────────────────

Botones: Inter 600, versalitas, tracking 0.08em; reposo plano, hover eleva.
Cards: hairline 2px + lift; la destacada suma línea de marca.
Gauge circular (.uig-gauge): 44×44px, conic-gradient(--uig-red
  var(--uig-gauge-progress), #383842 0), hueco interior 36×36 #151518.
  Uso: <div class="uig-gauge" style="--uig-gauge-progress: 72%"><span>72</span></div>
Scrollbar: 6px, track #0e0e11, thumb #26262e (radius 3px), hover rojo.

── NOTAS DE ESTILO ──────────────────────────────

- Estética industrial densa, tipografía chica, acento rojo fuerte.
- Sin gradientes llamativos; vidrio muy sutil (opacidad 0.025).
- El tema se conmuta con [data-bs-theme="light|dark"] en <html>.
  Solo se reescriben tokens: ningún componente necesita reglas nuevas
  salvo alertas y botones outline (ver _theme-light.scss).


── REQUISITOS DE CONSUMO ────────────────────────

1. Fuentes (Google Fonts) → <link> en <head>:
   Barlow + Barlow Condensed + Inter
2. Bootstrap 5 CSS  → <link>, SIEMPRE antes de UiGas
3. UiGas            → <link> después de Bootstrap
4. Bootstrap JS     → <script bootstrap.bundle.min.js> para los componentes
                      interactivos (modal, dropdown, carousel, accordion,
                      offcanvas, toast, tooltip)

UiGas no incluye reboot, grid ni utilidades de layout.
