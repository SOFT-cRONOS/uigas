── NOTAS DE ESTILO ──────────────────────────────

- Estética oscura industrial, minimalista, con acento rojo fuerte.
- Botones: versalitas, tracking amplio, relleno plano en reposo; el hover los eleva.
- Cards: hairline + lift; la destacada suma borde de marca.
- Radios chicos (2–8px): sin chaflán.
- Vidrio muy sutil (opacidad 0.025) — nada translúcido pesado.
- Sin gradientes llamativos; cuando se usan, primary → secondary a 135deg.
- El tema se conmuta con [data-bs-theme="light|dark"] en <html>.
  Solo se reescriben tokens: ningún componente necesita reglas nuevas
  salvo alertas y botones outline (ver _theme-light.scss).


── REQUISITOS DE CONSUMO ────────────────────────

1. Fuentes UiGas (Google Fonts) → <link> en <head>
2. Bootstrap 5 CSS  → <link>, SIEMPRE antes de UiGas
3. UiGas            → <link> después de Bootstrap
4. Bootstrap JS     → <script bootstrap.bundle.min.js> para los componentes
                      interactivos (modal, dropdown, carousel, accordion,
                      offcanvas, toast, tooltip)

UiGas no incluye reboot, grid ni utilidades de layout.
