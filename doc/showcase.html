Fundamentos de uso
Cómo incluir UiGas, conmutar tema y qué tokens manda cada superficie. Todo sobre la paleta del Brandbook CVR 2027: Asphalt Black #141414 y Racing Red #f92121.
1 · Orden de inclusión
Racing Red · señal
Slab · texto blanco
--uig-bg
--uig-surface
--uig-line
--uig-text-muted

Dos rojos, un solo origen: #f92121 es la señal de marca (enlaces, focus, bordes, tintes) y #e10600 solo aparece en superficies sólidas que sostienen texto blanco, donde cumple 4.97:1.

<!-- 1. Bootstrap CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- 2. Fuentes UiGas (Korataki marca/logo vía local() · Barlow Condensed display · Barlow cuerpo · Rajdhani datos) -->
<link href="https://fonts.googleapis.com/css2?family=Barlow:ital,wght@0,400;0,500;0,600;0,700;1,400;1,600;1,700&family=Barlow+Condensed:ital,wght@0,400;0,600;0,700;0,900;1,700;1,900&family=Rajdhani:wght@400;500;600;700&display=swap" rel="stylesheet">

<!-- 3. UiGas · SIEMPRE después de Bootstrap -->
<link rel="stylesheet" href="dist/uigas.min.css">

<!-- 4. Bootstrap JS al final del body -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
2 · Tema claro / oscuro

El tema se conmuta con data-bs-theme en <html>. Este showcase recuerda tu elección y, sin elección previa, respeta la del sistema.

<!-- Tema inicial (en <head>, antes del paint) -->
<script>
  var t = localStorage.getItem('uig-theme')
    || (matchMedia('(prefers-color-scheme: light)').matches ? 'light' : 'dark');
  document.documentElement.setAttribute('data-bs-theme', t);
</script>

<!-- Conmutar -->
<script>
  function setTheme(t) {
    document.documentElement.setAttribute('data-bs-theme', t);
    localStorage.setItem('uig-theme', t);
  }
</script>

5 · Voz tipográfica (Brandbook CVR §06)
Cada décima cuenta
--uig-font-h1 · Barlow Condensed · H1 y display (legible)
UiGas
--uig-font-brand · Korataki Bold Italic · SOLO logo y marca
Clasificación · Sector 2
--uig-font-display · Barlow Condensed · títulos, etiquetas y controles
Barlow es la voz del cuerpo: párrafos, descripciones y ayuda. Legible en pantalla y en papel, con un ritmo editorial limpio que deja respirar el contenido.
--uig-font-body · Barlow · cuerpo de texto
1:23.456 · GAP +0.812s · LAP 18/32
--uig-font-data · Rajdhani · EXCLUSIVO de datos: tiempos, posiciones, telemetría

Cuatro voces, cuatro rangos. Korataki es comercial y no vive en Google Fonts: uigas.min.css la declara con @font-face + local() y la reserva para la marca (logo y menciones del nombre), con Barlow Condensed 900 itálica de fallback. Los H1 y display usan Barlow Condensed, que se lee mejor en títulos largos. Rajdhani no se usa nunca para texto corrido.

01
Buttons
Reposo plano y sólido. El lift, el glow y el anillo viven solo en hover, focus y press. primary y danger recorren el rampón rojo CVR en direcciones opuestas: el primero se profundiza, el segundo se enciende.
Ejemplo 1 · Jerarquía de color
<button class="btn btn-primary">Primary</button>
<button class="btn btn-danger">Danger</button>
<button class="btn btn-secondary">Secondary</button>
<button class="btn btn-light">Light</button>
<button class="btn btn-dark">Dark</button>
Ejemplo 2 · Outline, ghost, loading y tamaños
<!-- Tamaños -->
<button class="btn btn-outline-primary btn-lg">Large</button>
<button class="btn btn-outline-primary btn-sm">Small</button>

<!-- Ghost: acción terciaria, sin chrome hasta el hover -->
<button class="btn btn-ghost">Ghost</button>

<!-- Loading: el spinner reemplaza la etiqueta -->
<button class="btn btn-primary btn-loading">Guardando</button>
